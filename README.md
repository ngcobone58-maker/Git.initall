### 1. Jokes Generator (Talking Aviator)
A fun random joke generator with a talking aviator character.

- Speaks the jokes using the browser’s speech synthesis
- Animated aviator that talks

**Location:** `Jokes-generator-talking-aviator`

Starter code for an AI Bot Guide App.

**Location:** `package.json` + `web/`

## How to run the Jokes Generator
1. Open the file `Jokes-generator-talking-aviator` in your browser
2. Click **Get Joke** or click the aviator
